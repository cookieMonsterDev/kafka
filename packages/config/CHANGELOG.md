# @cookiemonsterdev/kafka-config-v1.0.0 (2026-08-28)

Initial release. Extracted from `@cookiemonsterdev/kafka-core`'s `./config` subpath into a
standalone, zero-runtime-dependency package: `<name>.config.*` file discovery, sync/async loading,
a TypeScript transform rescue, layer merging, and diagnostics — generic, with no knowledge of Kafka
or any other specific consumer.

### Features

- add `discoverConfigFile`, `CANDIDATE_EXTENSIONS` for `<name>.config.*` / `.config/<name>.*`
  discovery, with a configurable `name` (default `'kafka'`)
- add `loadConfigFileSync` / `loadConfigFileAsync`, generic over a `T` config shape with an
  injected `assertValid` validator
- add `createDefineConfig({ objectSections })` to build a `defineConfig` + `assertValid` pair
  scoped to a consumer's own known sections
- add `mergeConfigLayers(override, base, { shallowMergeKeys })` with `undefined`-is-absent merge
  semantics, atomic replacement by default
- add the TypeScript transform-hook rescue (`installConfigTransformHooks`,
  `areConfigTransformHooksInstalled`) for TS enums, extensionless imports, and `export default`
  under a CommonJS-resolved file
- add `KafkaConfigError` / `KafkaConfigRequiresAsyncError`, `.name`-matchable typed errors, and the
  `onDiagnostic` diagnostics channel (`defaultOnConfigDiagnostic`, `ConfigDiagnostic`)
