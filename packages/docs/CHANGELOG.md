### BREAKING CHANGES

- Partitioners.JavaCompatiblePartitioner is no longer
  exported. Use Partitioners.DefaultPartitioner for murmur2 keyed routing.
- lingerMs now defaults to 5, batchSize to 16384,
  and maxInFlightRequests to 5. Pass lingerMs: 0 for one Produce per
  send, or maxInFlightRequests: null to uncap. throughputPreset() now
  only sets sticky partitioning, bufferMemory, and consume concurrency.
