# @cookiemonsterdev/kafka-cli-v0.0.1 (2026-08-30)

Name-reservation release, published by hand ahead of the walking skeleton. The package is still
the private-turned-public workspace scaffold from the CLI package-scaffold track: no `bin` entry,
no commands, no runtime behavior beyond `export {}`. Its only purpose is to make
`@cookiemonsterdev/kafka-cli` exist on the npm registry so npm Trusted Publishing can be configured
for it before the first real release.

The walking skeleton's first commit is expected to carry a breaking-change marker so semantic-release
computes the next version as `1.0.0` from this `0.0.1` baseline, matching every version already
promised for it elsewhere in this repo's release history.
